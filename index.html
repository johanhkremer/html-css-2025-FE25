Flexbox - one-dimensional layouts

Flexbox is useful when you want to arrange elements along a single axis (horizontal or vertical), manage spacing, and reorder items individually.

Common CSS rules (Flexbox)

display: flex
Enables flex layout on a container.
flex-direction: row | column
Chooses the main axis: row (default) or column.
flex-wrap: nowrap | wrap
Defines whether items should wrap to a new line/column.
gap: 1rem
Sets spacing between flex items.
justify-content
Aligns items along the main axis (flex-start, center, space-between, etc.).
align-items
Aligns items along the cross axis (stretch, center, etc.).
align-content
Aligns multiple rows of items (requires flex-wrap and extra space).
flex: grow shrink basis
Shorthand for how an item grows/shrinks (e.g. flex: 1 1 200px;).
order
Controls the visual order of an item (doesn't affect HTML order).
align-self
Overrides align-items for a single item.

CSS Grid - two-dimensional layouts

Grid is perfect when you need to create two-dimensional layouts with rows and columns and have precise control over placement and span.

Common CSS rules (Grid)

display: grid
Enables grid layout on a container.
grid-template-columns
Defines columns (e.g. repeat(3, 1fr), 200px 1fr).
grid-template-rows
Defines rows (e.g. auto 1fr auto).
gap, column-gap, row-gap
Sets spacing between rows and columns.
grid-auto-rows, grid-auto-columns
Sets the size of automatically created rows/columns.
grid-auto-flow: row | column | dense
Controls how items are placed if not explicitly positioned.
justify-items / align-items
Aligns content inside each grid cell (horizontal/vertical).
justify-content / align-content
Aligns the entire grid within the container.
grid-column / grid-row
Places an item (e.g. grid-column: 1 / 3; spans two columns).
place-items / place-content / place-self
Shorthand for setting both justify- and align- values at once.
